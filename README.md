# 전세ONE — 전세사기 원스톱 대응 (정적 MVP)

전세사기 예방·대응이 필요한 1인가구 청년을 위한 **순수 정적 웹사이트**입니다.
서버 0 · 계정 0 · 월비용 0. 개인 데이터는 이 기기의 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다.

> ⚠️ 본 사이트는 참고용 정보 도구이며 **법률자문이 아닙니다.** 개별 사안은 반드시 공식 창구(전세피해지원센터, 대한법률구조공단 등)에서 확인하세요.

## 기능
- **F1 상황 라우터** — 계약전/계약중/사고발생/피해자신청/부결 5택
- **F2 위험도 계산기 + 단계별 체크리스트** — 보증금·집값·선순위로 신호등(안전/주의/위험), 체크상태 localStorage 저장
- **F3 증거함** — 계약·문자·이체내역 타임라인 기록, JSON 내보내기/불러오기
- **F4 자원 지도** — 상황·지역별 지원 창구 필터
- **F5 부결 대응 트랙** — 이의신청·재신청·민사·대체지원 순서
- **F6 지역 지원 조회** — 시도→시군구 선택 (예시 데이터)
- **F7 서류 템플릿** — 내용증명 등 입력값으로 채워 .txt 다운로드/인쇄

## 실행 방법

### 1) 권장: 정적 서버로 열기 (GitHub Pages와 동일 동작)
```bash
# 이 폴더에서
python -m http.server 4180
# 브라우저에서 http://localhost:4180 접속
```
VS Code Live Server, `npx serve` 등 어떤 정적 서버든 됩니다. http 환경에서는 `data/*.json`이 정본으로 사용됩니다.

### 2) 파일 더블클릭(file://)으로 열기
`file://`에서는 브라우저가 `fetch('data/*.json')`을 차단하므로, 미리 생성해 둔 `data/_bundle.js`(전역 데이터 번들)를 폴백으로 사용합니다. 저장소에 이미 포함되어 있어 그대로 열면 동작합니다.

## 데이터 수정 방법
1. `data/*.json`을 편집합니다. (모든 항목에 `updated` 필드 = 최종확인일 필수)
2. `file://` 폴백을 최신으로 유지하려면 번들을 다시 생성합니다:
   ```bash
   node tools/build-bundle.mjs
   ```
   → `data/_bundle.js`가 갱신됩니다. (Node만 필요, 의존성 0)

## 배포 (GitHub Pages)
- 이 폴더를 저장소 루트로 push → Settings → Pages → 루트 배포.
- 모든 경로가 상대경로(`assets/...`, `data/...`)라 서브경로에서도 동작하며, 해시 라우터라 새로고침 404가 없습니다.
- `tools/`는 개발용이므로 배포에서 제외해도 됩니다(포함해도 무해).

## 구조
```
index.html            SPA 셸 (스크립트 로드 순서 고정)
assets/css/           tokens · base · components
assets/js/            util · data · store · risk · router · app + views/*
data/*.json           수기 관리 데이터 (정본)
data/_bundle.js       file:// 폴백 (생성물)
tools/build-bundle.mjs 번들 생성기 (개발용)
```

## 개인정보·보안
- 원격 전송 코드 0건. 외부 요청은 동일 오리진 `data/*.json` 로드와 Pretendard 폰트 CDN뿐입니다.
- 사용자 입력·불러온 JSON은 표시 시 텍스트로만 처리(스크립트 실행 경로 없음).
- 증거함 데이터는 이 기기에만 저장됩니다. 브라우저 데이터를 지우면 삭제되니 **내보내기로 백업**하세요.
